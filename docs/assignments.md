# Assignment 1 — Documentation and GitHub Pages Setup

## What was the goal?

My goal was to create a website to document my Digital Fabrication coursework and share my learning process online. I wanted a space where I could organise my assignments, describe my design process, and record the results of my work.

## What did I do?

I created a public GitHub repository called digital-fabrication. I added a mkdocs.yml configuration file and created Markdown pages inside the docs folder.

I set up a GitHub Actions workflow to build the website with MkDocs and publish it through GitHub Pages. I added Home, About Me, Assignments, and Projects pages.

I also downloaded the repository as a ZIP file and opened the docs folder in Obsidian to edit my documentation.

## What tools and materials did I use?

I used GitHub to store my files, GitHub Pages to publish the website, MkDocs to generate the pages, and Markdown to write the content. I also used Obsidian to work with the documentation locally.

The project required a computer and an internet connection.

## What went wrong?

While adding new coursework, I found that uploading a Markdown file to GitHub did not automatically make it appear in the website menu. I also needed to distinguish between the repository’s main folder and the docs folder used by MkDocs.

## What did I change? How did I solve the problem?

I placed the documentation pages inside the docs folder and updated the navigation settings in mkdocs.yml.

I organised the website so that the top navigation contains a single Assignments button. Inside the assignment pages, a sidebar provides links to individual assignments and their questions.

## What was the result?

I created a website for my Digital Fabrication coursework. It provides a structure for documenting my goals, tools, process, challenges, changes, and results.

I can now add new assignment pages and connect them through the sidebar as my coursework develops.
